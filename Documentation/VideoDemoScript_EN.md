# Phase 2 — Video Demonstration Script (English, ~3–5 minutes)

**You must record the actual Windows application and Visual Studio on your machine.** These notes are a script, not a recorded demonstration.

1. **Visual Studio Solution Explorer**: “This is my Olive Branch Bakes Phase 2 project, built from my Phase 1 .NET 8 Windows Forms solution. I organized it into Forms, Models, Services, Assets, Navigation, and Documentation. The original Phase 1 files are backed up under Documentation/Phase1Original.”
2. **Class architecture**: “These Models and Services are documented placeholders only. Order processing, authentication and other business logic are reserved for later phases.”
3. **Navigation diagram**: open `Documentation/NavigationDiagram.png`. “Customers start at Welcome and can visit Order, Account and Order Summary. Staff enter through Administrator Login and can preview the Admin Console. The shared top bar and back buttons support return navigation.”
4. **Run application**: press F5. “This is the cottage bakery color palette: cream, olive green, warm brown, honey gold, and a restrained terracotta accent. The labels use readable fonts.”
5. **Customer prototype**: select **ORDER**. Show bakery products, categories, basket layout, and pickup selection. Click **ADD +**; show that a *demo notice* appears, not a real cart mutation. Then navigate to **SUMMARY** and **ACCOUNT** and back.
6. **Admin flow**: select **STAFF**; choose **OPEN ADMIN CONSOLE PREVIEW** and return to login. “Authentication and the dashboard data will be built later.”
7. **Tablet suitability**: point to large buttons and readable labels, resize the window (do not shrink below minimum) and scroll vertically. Demonstrate **Tab** key between controls. “Large buttons, a scrollable content area and readable fonts support Windows touch screens and PCs in landscape orientation.”
8. **Finish**: “This is Phase 2: architecture and interface prototypes, not a functioning ordering system.”

**Recording tip:** Windows 11 Snipping Tool > Record or PowerPoint Screen Recording; capture the application, Solution Explorer, and navigation image in one short video.
